# Rejected Olympic Sports

Entry for the [Rejected Olympic Sports](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da) bounty on [make.fun](https://make.fun).

One funny single-line sport the Olympics rejected: the Men's 100-Metre
Wi-Fi Password Shout — athletes sprint while yelling the router
password, and gold goes to the first one the neighbours can actually
understand.

## Run

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt`. The line is UTF-8
text of 1 to 200 characters, one line, not only whitespace — the exact
gate the competition's sealed scorer checks before the entry goes
before the house AI judge. The line is composed in `main.py` from three
parts — event name, action, medal rule — joined as
"<event>: <action>; <rule>." so each part earns its place.

## Entry

> Men's 100-Metre Wi-Fi Password Shout: athletes sprint while yelling
> the router password; gold goes to the first one the neighbours can
> actually understand.
